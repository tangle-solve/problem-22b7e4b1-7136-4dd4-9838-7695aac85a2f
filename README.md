### ALGO-000128: Deterministic k-server conjecture
- **Subfield:** Online algorithms and streaming
- **Open:** Give a deterministic \(k\)-competitive algorithm for the \(k\)-server problem on every metric space.
- **Status:** Proposed in 1988. The work-function algorithm gives the classical \(2k-1\) general guarantee; the target \(k\) remains open.
- **Type:** theory
- **Why:** Would resolve a central model unifying paging, movement, and online service.
- **Key works:** Manasse, McGeoch, and Sleator (1990), *Competitive Algorithms for Server Problems*; Koutsoupias and Papadimitriou (1995), *On the k-Server Conjecture*.
